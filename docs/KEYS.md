# 🔑 Getting a free KLIPY API key · Cómo conseguir una clave gratuita de KLIPY

The KLIPY GIF search in WaDesktop-Tweaks is **optional**. Without a key nothing changes: you keep WhatsApp's own GIFs.
La búsqueda de GIFs de KLIPY es **opcional**. Sin clave no cambia nada: sigues usando los GIFs de WhatsApp.

## English

1. Go to **<https://partner.klipy.com>** and create a free account.
2. Open **API Keys** and create a new key (platform).
   - **Key name**: anything, e.g. `WaDesktop-Tweaks`.
   - **URL**: any website you own (for example your GitHub profile).
   - Leave the **Ads API** switch **off**.
3. Copy the key that is shown.
4. In WhatsApp Desktop: **⚙ → GIFs →** paste it into **KLIPY API key**.
5. Open a chat → emoji button → **GIF** tab → choose **Klipy** above the search box.

**Notes**
- Keys start in *Testing* mode (about 100 requests per hour). That is plenty for personal use; you can request production access in the KLIPY panel.
- The **content filter** setting controls how strict KLIPY is (`off`, `low`, `medium`, `high`). `off` may return adult content.
- Your key is stored only on your PC (in WhatsApp's browser profile) and is sent only to `api.klipy.com`.
- KLIPY asks for attribution; the picker labels the source as "Klipy".
- Never share your key publicly or commit it to a repository.

## Español

1. Entra en **<https://partner.klipy.com>** y crea una cuenta gratuita.
2. Abre **API Keys** y crea una clave nueva (plataforma).
   - **Key name**: lo que quieras, por ejemplo `WaDesktop-Tweaks`.
   - **URL**: cualquier sitio tuyo (por ejemplo tu perfil de GitHub).
   - Deja el interruptor de **Ads API** **desactivado**.
3. Copia la clave que aparece.
4. En WhatsApp Desktop: **⚙ → GIFs →** pégala en **Clave de API de KLIPY**.
5. Abre un chat → botón de emojis → pestaña **GIF** → elige **Klipy** sobre el buscador.

**Notas**
- Las claves empiezan en modo *Testing* (unas 100 peticiones por hora). Es suficiente para uso personal; puedes pedir acceso de producción en el panel de KLIPY.
- El ajuste **filtro de contenido** controla qué tan estricto es KLIPY (`off`, `low`, `medium`, `high`). `off` puede devolver contenido para adultos.
- Tu clave solo se guarda en tu PC (en el perfil del navegador de WhatsApp) y solo se envía a `api.klipy.com`.
- KLIPY pide atribución; el selector etiqueta la fuente como «Klipy».
- No compartas tu clave públicamente ni la subas a un repositorio.
