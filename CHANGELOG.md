# Changelog

## 0.1.0 — first release

- Browser-extension architecture: no Node.js, no helper process, no open debugging port.
- Privacy: deferred read receipts, hide typing / recording / online, don't mark voice notes as played, view statuses
  without notifying.
- Messages: local copy to recover deleted messages (shown inline), edit history (click the ✏️; your own edits too),
  deleted & edited log with search. Emoji the system font cannot draw are shown as ❔ in the tweaks' own panels.
- Statuses: optional archive with per-contact selection and a size cap.
- GIFs: KLIPY search sent through WhatsApp's native GIF flow.
- Comfort: double-click reactions, sticker confirmation, seconds in timestamps, save-media button, hide "Forwarded",
  quick replies, keyword highlight, export chat to .txt / .json.
- Appearance: bubble colours, compact mode, smooth mouse-wheel scrolling, hide Channels / Communities / Meta AI / Status, custom CSS.
- Screen privacy: blur (also covers the tweaks' own buttons, toasts and dialogs), PIN lock, panic button.
- Scheduled messages (high risk, off by default); a message is removed from the list once it has been sent.
- Settings panel with a search box over every option; profiles, settings backup/restore, update check, uninstaller.
- Self-diagnosis with a copyable, privacy-safe layout report.
- 13 interface languages.
